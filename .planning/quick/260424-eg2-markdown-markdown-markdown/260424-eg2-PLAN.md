**1. `_strip_markdown(text: str) -> str`**
用正则去除常见 Markdown 符号，返回纯文本（用于卡片摘要）：
- `**text**` / `*text*` / `__text__` / `_text_` → text（去粗/斜体标记）
- `# ` / `## ` / `### ` 行首标题标记 → 去掉 `#` 和空格
- `- ` / `* ` 行首无序列表标记 → 去掉
- 使用 `re.sub`，全部写在一个方法内

```python
def _strip_markdown(self, text: str) -> str:
    import re
    text = re.sub(r'\*\*(.+?)\*\*', r'\1', text)
    text = re.sub(r'\*(.+?)\*', r'\1', text)
    text = re.sub(r'__(.+?)__', r'\1', text)
    text = re.sub(r'_(.+?)_', r'\1', text)
    text = re.sub(r'^#{1,3}\s+', '', text, flags=re.MULTILINE)
    text = re.sub(r'^[-*]\s+', '', text, flags=re.MULTILINE)
    return text
```

**2. `_render_markdown_in_widget(widget, text: str)`**
将 Markdown 文本渲染到 tk.Text widget（只读预览）：
- 先配置 tag（每次调用都重新 configure，保证主题正确）：
  - `'h1'`: font=('PingFang SC', 18, 'bold'), foreground=th['FG_ACCENT']
  - `'h2'`: font=('PingFang SC', 15, 'bold'), foreground=th['FG_ACCENT']
  - `'h3'`: font=('PingFang SC', 13, 'bold'), foreground=th['FG_ACCENT']
  - `'bold'`: font=('PingFang SC', 13, 'bold')
  - `'italic'`: font=('PingFang SC', 13, 'italic')
  - `'bullet'`: lmargin1=24, lmargin2=32（缩进）
- 清空 widget，state=NORMAL，逐行解析并 insert：
  - 行以 `### ` 开头 → strip 标记，insert + tag_add 'h3'
  - 行以 `## ` 开头 → strip，insert + tag_add 'h2'
  - 行以 `# ` 开头 → strip，insert + tag_add 'h1'
  - 行以 `- ` 或 `* ` 开头 → 前缀改为 `• `，insert + tag_add 'bullet'
  - 其他行：逐段解析行内 bold（`**...**`）和 italic（`*...*`），分段 insert + tag_add
    - 用 `re.split(r'(\*\*[^*]+\*\*|\*[^*]+\*)', line)` 拆分行内标记
    - `**text**` → tag 'bold'；`*text*` → tag 'italic'；其余 → 无 tag
  - 每行末尾 insert `'\n'`
- 最后 state=DISABLED（预览只读）

```python
def _render_markdown_in_widget(self, widget, text: str):
    import re
    th = THEMES[self._theme_mode]
    widget.tag_configure('h1', font=('PingFang SC', 18, 'bold'),
                         foreground=th['FG_ACCENT'])
    widget.tag_configure('h2', font=('PingFang SC', 15, 'bold'),
                         foreground=th['FG_ACCENT'])
    widget.tag_configure('h3', font=('PingFang SC', 13, 'bold'),
                         foreground=th['FG_ACCENT'])
    widget.tag_configure('bold', font=('PingFang SC', 13, 'bold'))
    widget.tag_configure('italic', font=('PingFang SC', 13, 'italic'))
    widget.tag_configure('bullet', lmargin1=24, lmargin2=32)

    widget.configure(state=tk.NORMAL)
    widget.delete('1.0', tk.END)

    for line in text.splitlines():
        start = widget.index(tk.INSERT)
        if line.startswith('### '):
            widget.insert(tk.END, line[4:] + '\n', 'h3')
        elif line.startswith('## '):
            widget.insert(tk.END, line[3:] + '\n', 'h2')
        elif line.startswith('# '):
            widget.insert(tk.END, line[2:] + '\n', 'h1')
        elif re.match(r'^[-*] ', line):
            widget.insert(tk.END, '• ' + line[2:] + '\n', 'bullet')
        else:
            parts = re.split(r'(\*\*[^*]+?\*\*|\*[^*]+?\*)', line)
            for part in parts:
                if part.startswith('**') and part.endswith('**'):
                    widget.insert(tk.END, part[2:-2], 'bold')
                elif part.startswith('*') and part.endswith('*'):
                    widget.insert(tk.END, part[1:-1], 'italic')
                else:
                    widget.insert(tk.END, part)
            widget.insert(tk.END, '\n')

    widget.configure(state=tk.DISABLED)
```

def _notes_toggle_preview(self):
    """编辑/预览切换（仅在 edit 模式下有效）。"""
    if self._notes_mode != 'edit':
        return
    th = THEMES[self._theme_mode]
    self._notes_previewing = not getattr(self, '_notes_previewing', False)
    if self._notes_previewing:
        # 进入预览：读取当前文本并渲染
        content = self._notes_text.get('1.0', tk.END).rstrip('\n')
        self._render_markdown_in_widget(self._notes_text, content)

        self._notes_save_btn.pack_forget()   # 预览时隐藏保存
